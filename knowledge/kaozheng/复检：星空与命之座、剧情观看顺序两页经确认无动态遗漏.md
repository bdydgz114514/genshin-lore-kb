## 摘要

复查此前被标为「内容偏少」的 stars/base.html 与 Linear/base.html，确认是否存在动态加载导致的内容遗漏；结论是两页均为纯静态、记录完整，仅 Linear 的「序号列」措辞需精确化。

## 正文

【补了什么缺口】
此前 22 条整理中，「日月全事/星空与命之座」（stars.json）与「日月全事/剧情观看顺序」（linear.json）两页当时内容偏少，需要对它们做一次「是否有动态加载导致遗漏」的复检：如果这两页也像 interestfacts.html 那样是前端渲染的，那么先前记下的条目就是不完整的。
本次逐页实测后结论明确：**这两页都是纯静态 HTML，没有动态遗漏**；其中 Linear 的一处措辞需要精确化修正。

■ 材料三：Linear 页上唯一的额外脚本是纯 UI，不含内容
·出处：https://genshinlore.cn/Linear/marker.js（3094 字节）
·源码头部注释原文照录：「marker.js — 表格行标记功能　为表格每一行添加复选框和ID列，选中后整行添加删除线并变灰。」
·存储键原文：var STORAGE_KEY = 'GenshinLore_marker_checked_ids';，用 window.localStorage 存取。
→ 这解释了为什么页面文字说「每一行前面的复选框可以标注自己已经看过的剧情，数据全部存储在浏览器本地」，而静态 HTML 里复选框数量为 0：**复选框是 marker.js 运行时注入的，只承载「我看到第几条」的个人进度，不是内容**。原条目对此的描述（「数据全部存储在浏览器本地，不会上传到服务器」）**成立**。
→ 因此 Linear 页无任何动态内容遗漏。

■ 材料四：关于 tools/fetch-any 在这两页上的一个误判（复现方法）
·现象：node fetch-any.mjs "https://genshinlore.cn/basiclore/stars/base.html" 回报 尝试: direct=cloudflare(6855B) -> proxy=network(0B) -> browser=cloudflare(89857B)，最终「未取到内容」。
·但该 URL 用直连取回的内容是**正常页面**：<title>星空 - 基本设定</title>，全文不含 "Just a moment"，正文即材料一那 236 字。
·成因：fetch-any.mjs 的 classifyBlock() 用 CHALLENGE_PAT = /(Just a moment|请稍候|cf-challenge|challenge-platform|Checking your browser|Attention Required|cf-browser-verification)/i 扫描响应体的**前 8000 字符**；而 genshinlore.cn 每个页面页脚都内嵌 Cloudflare 的 /cdn-cgi/challenge-platform/scripts/jsd/main.js，该串在此页位于第 5808 字符处，落进检测窗口 → 被误判为「Cloudflare 人机挑战」。
·影响面：字符数较小的页面都会被误伤（实测 stars/base.html 7594 字节即命中）；页面较大时该串落到 8000 字符之后，反而正常（about.html、Linear/base.html 均未被误判）。
·处置：改用直连（node fetch 或等价方式）取原文即可，页面本身是 200 正常内容。

【对原结论的影响】
① 支持原结论（两页均无动态遗漏）＋对其中一处措辞作精确化修正。
1. stars/base.html：**支持**。原条目记录的 3 条要点与 1 句用语与原文逐字一致，该章篇幅本来就极短，不存在动态加载遗漏。
2. Linear/base.html：**支持**。192 条、六种类型、版本跨度、6 处前置／后置材料备注等原记录均在静态 HTML 中可验证，不存在动态加载遗漏；页面唯一的额外脚本 marker.js 只提供本地阅读进度标记。
3. 唯一需改的一处措辞（属精确化，不改结论）：原条目「「序号」列在纯文本快照中未逐行填充数值」→ 应改为「**「序号」列在源 HTML 表格中就没有任何数据单元格**（数据行每行仅 7 个 <td>，不含序号列）」。
4. 附带的方法论结论：经本次全站排查，该站**只有 interestfacts.html 一页存在「内容全在 JS 里」的情形**（正文由 interestfacts.json 提供），另加 about.html 的版本修改记录「HTML 独有、md 里没有」。其余页面要么纯静态，要么其动态内容恰好已由 md/*.md 取得。因此先前的 22 条在「动态加载」这一维度上，除 interestfacts 与 about 外没有系统性问题。

【仍然查不到的】
1. stars 页正文只有 3 条要点，**没有任何脚注编号或出处**（页面无 <sup> 脚注、无参考资料区块）；因此「法涅斯用蛋壳隔绝宇宙和世界的缩影」这一句具体出自哪条游戏内文本，**本页无法核验**——这属于手册自身的引用粒度问题，不是抓取问题。
2. Linear 页表格中「序号」列既然在 HTML 中为空，**该列是否曾有计划填入**（例如与 ID 并列的另一种排序号）无从得知；页面上也没有说明。此处不代填。
3. Linear 表第 192 条之后是否还有新增条目，取决于手册更新；页面本身无「本页最后更新」时间戳，**时效性无法确定**（about.html 的版本记录显示网站版停更于第3版「苍星圣敕」，见另一条补证）。
4. 第 192 行「月之七｜活动｜幻友绮旅」的「章节」列为空，**原表此处就是空的**，未填写章节名；不是抽取遗漏。
