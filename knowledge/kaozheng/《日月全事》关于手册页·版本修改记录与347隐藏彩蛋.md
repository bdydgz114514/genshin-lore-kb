## 正文

【补了什么缺口】
此前整理《日月全事》「关于手册」页时，条目「日月全事/编者后记与方法论」（website-entries/about.json）取的来源是 Markdown 源文件 https://genshinlore.cn/md/about.md，solution 里只写了一句「第四幕『世界「补完」计划』指向页面顶部的版本修改记录」——**没有落地任何一条版本记录**。
本次复查 about.html 本体，发现该页内容其实分两部分：一部分由 aboutcontent.js 从 md/about.md 动态载入（这部分原条目已完整收录），另一部分——包括完整的「版本修改记录」和一个需要输入密码才触发的隐藏彩蛋——**只写在 about.html 的 HTML 里，md/about.md 中查无此文**。本条目补上这两块。

【新取得的材料】

■ 材料一：证明「版本修改记录」只存在于 HTML（出处：https://genshinlore.cn/about.html，54835 字符；对照 https://genshinlore.cn/md/about.md，129638 字节）
在 md/about.md 全文检索以下字符串，结果全部为 absent（不存在）：「2026.07.01」「2026.05.11」「苍星圣敕」「Palestar」「第3版」「第8.5版」。
md 里只有一句指路，原文：「（见页面顶部的"版本修改记录"）」。
而 https://genshinlore.cn/aboutcontent.js（34109 字符 / 37997 字节）是「关于页面内容加载与渲染模块」，其源码注释原文：「负责从 Markdown 文件加载"关于手册"页面的内容，解析脚注、表格、标题层级，并生成目录导航」，加载路径为 const mdPath = 'md/about.md';，写入的容器是 document.getElementById('about-content')。版本修改记录不在该容器内，它是 HTML 里独立的 <details> 折叠块。
→ 因此：**只抓 md/about.md 会系统性漏掉整张版本修改记录表**。

■ 材料二：页首停更横幅（出处：https://genshinlore.cn/about.html，原文照录）
「网站已暂时停更，内容维持「第3版 苍星圣敕」的内容，新的修改暂不更新。《日月全事：苍星圣敕·至冬史略一》的内容与之前的《日月全事：苍星圣敕》相比，仅在至冬部分有大量改动，如需查看相应的文本内容，请下载PDF版查看。」
（同句亦见于 https://genshinlore.cn/main.html）
→ 这条给出了手册当前的**权威版本锚点**：网站版＝第3版「苍星圣敕」；更新的「至冬史略一」只在 PDF 里，网站没有。

■ 材料四：两条此前未收录的**体例钥匙**（出处：同上，原文照录）

【对原结论的影响】
② 修正/补充原结论（原结论无被推翻部分，属增补＋定性修正）。
1. 原条目对 md/about.md 内容的整理（编者后记、随书附赠册、〈special〉One Last World、〈end〉艾尔海森引文）**经复核逐项成立，保持不变**。
2. 需增补：原条目只写了「第四幕『世界「补完」计划』指向页面顶部的版本修改记录」，实际该表有 **12 个版本条目**，且**只存在于 about.html**。引用手册版本沿革（例如「网站版停更于第3版苍星圣敕」）时必须以 about.html 为准，md/about.md 不可作依据。
3. 需增补：两条体例钥匙（【待发现】标识、删除线＝因果级删除）。这两条直接影响对正文的解读，应写入世界观整理条目。
4. 需增补：隐藏彩蛋「347」的谜面、答案与三层覆层演出。
5. 方法论提示（本次最有迁移价值的一条）：**该站的 Markdown 版并非 HTML 版的超集**。about.html 的正文由 aboutcontent.js 从 md/about.md 载入，但版本修改记录与交互彩蛋是 HTML 独有的；反之 md 版专为纯文本／AI 读者准备（md.html 原文：「如果你的设备条件极差，以至于连简单的网页都打不开，本页面上提供了markdown版本供使用」「当然，你也可以使用这些文件训练AI或者构建知识库」）。**结论：md 与 HTML 需互为补充，不可只取其一。**
