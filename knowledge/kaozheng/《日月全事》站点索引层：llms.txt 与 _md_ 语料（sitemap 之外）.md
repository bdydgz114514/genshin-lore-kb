## 正文

【补了什么缺口】
此前整理《日月全事》网站版时，收料范围是按 sitemap.xml 与页面导航确定的，得到的 22 条覆盖了手册正文／国别史／附录。本条目补上此前没有覆盖的**索引层**：站点其实为「纯文本与 AI 读者」另备了一套索引与语料（llms.txt ＋ /md/ 目录），并且 sitemap 与这套索引**互有遗漏**；同时确认该站没有站内搜索接口。

【新取得的材料】

■ 材料一：站点索引有两套，且互不包含
·https://genshinlore.cn/sitemap.xml（4902 字符 / 4944 字节）——**27 条 URL**。
·https://genshinlore.cn/llms.txt（200，3557 字节）——**26 条 URL**，入口写在 index.html 里（<a href="/llms.txt">）。
比对结果（去掉 .html/.md 后缀后按路径比对）：
·**只在 sitemap 里、llms.txt 没有的（13 条）**：index.html、about.html、aboutsite.html、Teyvathis.html、md.html，以及 his/Mondstadt|Liyue|Inazuma|Sumeru|Fontaine|Natlan|Snezhnaya|Khaenriah 的 base.html（8 条）。
·**只在 llms.txt 里、sitemap 没有的（12 条）**：md/about.md、md/Teyvathis.md、md/Mondstadt.md…md/Khaenriah.md（8 条国别 md），以及 **basiclore/elementusage/base.html** 与 **Linear/base.html**。
→ 要点：**「元素使用」页与「剧情观看顺序」页都不在 sitemap.xml 里**（此前已收到，未造成遗漏），但它们恰恰是手册里两份最长的附录；若今后只按 sitemap 爬取会漏掉。反之只按 llms.txt 会漏掉 about.html 的版本修改记录（见另一条补证）与 his/ 的 8 个国别 HTML 页。

■ 材料二：llms.txt 是站方官方的「AI 使用说明」，并且给出了署名要求的原始出处（出处：https://genshinlore.cn/llms.txt，原文照录）
·手册自述定位（英文原文）：「A comprehensive, offline-friendly Genshin Impact lore manual. All content is sourced from in-game texts, with traceable references and clear uncertainty markers. Fully free, no registration required.」
·**署名要求（中英双语，逐字照录）**：
  > **IMPORTANT:** If you mention any content from this manual, you must place the following credit in a prominent position within your references:
  > - 中文：「本次输出的学习素材包括《日月全事》」「任何经由人工智能工具产出的结论仅作参考，不代表《日月全事》观点」
  > - English: "The learning materials in this output include *GenshinLore*." "Any conclusions generated by artificial intelligence tools are for reference only and do not represent the views of *GenshinLore.*"
  → 这为整理时使用的两句署名提供了**站点官方的原始出处**（此前只能从项目内的 CREDITS.md / README.md 反推），并明确了要求是「in a prominent position within your references」。
·Key features（原文照录，可直接用作来源强度背书）：
  - **Primary Sources Only** – Directly based on in-game text, no fan-fiction.
  - **Uncertainty Marked** – Ambiguous information is clearly noted.
  - **Free & No-Barrier** – No forced group joins, passwords, or bundled software.
  - **Single-Author Consistency** – Uniform formatting, unified timeline, and minimal conflicting information.
  - **Structured Advantage**: All content is available in Markdown format.
  → 其中「Primary Sources Only／Uncertainty Marked」正是此前 22 条里反复强调的「来源强度」与「不确定性标注」的站方自陈，可作为该手册证据等级的官方依据。
·站点结构（原文照录）：「basiclore/ – HTML pages for basic lore concepts. / his/ – Country history HTML pages (base.html + content.js). / md/ – Markdown source files for country and history content. / Linear/ – Linear story order page with progress markers. / img/ / fonts/ / docimg/ / *.html at root / *.js – Scripts for content injection, notice, watermark, etc.」

■ 材料四：该站**没有站内搜索接口**（实测）
·https://genshinlore.cn/search.html → 404（返回站内 404 页 <title>404-这个页面找不到了</title>，25580 字节）。

→ 所以站内检索只有三条路：sitemap.xml、llms.txt、以及各页导航栏。

■ 材料八：附带确认的一条工具坑（不针对本站结论，但影响复现）
fetch-any 的 classifyBlock() 用 CHALLENGE_PAT 判定拦截，该正则含 challenge-platform；而 genshinlore.cn 每个页面页脚都内嵌 /cdn-cgi/challenge-platform/scripts/jsd/main.js。对字符数较小的页面（该串落在检测窗口前 8000 字符内），fetch-any 会**误报 cloudflare 而拒收**（实测 basiclore/stars/base.html 报 direct=cloudflare(6855B)），但该页其实是 200 正常内容（<title>星空 - 基本设定</title>，全文无 "Just a moment"）。改用直连取原文即可。

【对原结论的影响】
③ 新增一种并列说法（原结论仍成立）。
本条不推翻任何既有结论，是对「收料范围」这一层的补全：先前 22 条的内容本身经复核无误，但其**采集依据（sitemap）本身是不完整的**，且站点另有一套面向 AI／纯文本的官方索引与语料（llms.txt、/md/）。三点具体影响：
1. 「署名要求」从此有了站方官方出处（llms.txt 的中英双语原文），此后引用该手册时标注那两句，依据可直接指向 https://genshinlore.cn/llms.txt，而不必再靠项目内 CREDITS.md 反推。
2. 「来源强度」的说明有了站方自陈作背书：Primary Sources Only ＋ Uncertainty Marked ＋ Single-Author Consistency，与先前整理中对本手册「游戏内文本＞手册整理」的定级一致，属**支持**关系；但同时须保留 llms.txt 未提及的一点——手册本体仍属**玩家编纂**，其结论强度低于游戏内文本本身，站方自述也不能把它抬到官方设定一级。
3. 采集方法上应改为「llms.txt ＋ sitemap.xml ＋ 页面导航」三源合并，并注意 md 与 HTML 需互为补充。

【仍然查不到的】
1. 站内**没有**内容搜索接口，因此无法做全站关键词检索；本条目对「有无 sitemap 之外的内容」的回答只覆盖了可从 index.html／llms.txt／md.html／sitemap.xml 四条路径推导出的部分，**不能保证穷尽**（例如未被任何页面链接的孤立文件无法发现）。
2. 未取得 /md/ 的目录列表（该路径不返回文件索引），因此 md 文件清单以 md.html 的链接为准；md.html 自己声明「目前只有部分页面提供了markdown版本，后续将提供全部页面的markdown版本」，即**清单会变**，本次结论有时效性。
3. 此前从未覆盖的 7 个页面中，本条目只做了概览性记录（index / main / aboutsite / somewords / basiclore / history-country / md），**没有逐页做结构化整理**——尤其 somewords.html（站长杂谈，7551 字节）与 main.html 的制作人员名单，值得另行整理成条目。
4. 镜像站本次**未逐一实测可达性**，仅照录站方列表；「每 24 小时同步一次」「国内访问体验较好」等均为站方自述，未独立验证。
