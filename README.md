# 原神世界观知识库（多来源整理）

把三类《原神》世界观资料——**biligame 原神WIKI 全站、B站原学视频、genshinlore.cn《日月全事》手册**——
整理成一套结构化、可检索、**明确标注证据等级**的中文知识库，并对三者的冲突做了逐条考证。

> 本仓库不对任何说法做"官方认证"。每条结论都标注了它来自游戏内文本、手册、视频还是玩家推算。
> 有分歧的地方**保留分歧**，不做强行二选一。

## 这套知识库的特别之处

**1. 事实与推测严格分离。** 每条视频分析都强制分成六节，UP 主自己说"可能/我猜/没有证据"的内容
一律进【存疑或作者自述推测】节，绝不与游戏内可验证设定混写。

**2. 冲突不掩盖。** 10 条考证条目处理了这些分歧：

| 主题 | 分歧 | 处理 |
|---|---|---|
| 天理与法涅斯之名 | 「法涅斯」是本名还是《日月前事》的称呼 | 并列保留（层级不同可同真） |
| 葬火之战的年代 | 6000 年前 vs 3000 多年前 | 并列保留（分歧在"6000年"修饰什么） |
| 提瓦特尺度与虚假之天 | 数值是官方设定还是玩家推算 | 强制分层：官方只有定性一句 |
| 神之眼的发放者 | 七神发放 vs 光界发放 | 四说并列，采信"七神不决定发放" |
| 三月一星与少女 | 「第四个月亮」是月神位还是天体 | 用词义分层调和 |
| 散兵与刀匠事件 | 杀了很多刀匠 vs 改图纸+重伤家主 | 并列三说 + 证伪两处网络说法 |
| 花神与慈树王魔神名 | 有确定名 vs 未知 | 分层采信，判定"布耶尔=大慈树王"为误传 |
| 坎瑞亚原型 | 纳粹德国 vs 北欧/瓦格纳 | 采信命名层，其余并列 |
| 兹白/琅玕/三尸神 | 原型说是否成立 | 联网核验两条原典原文一致 |
| 尼伯龙根与第二王座 | 是否等同 | 四说并列 + 标出 WIKI 转述失准 |

**3. 连整理过程发现的证据瑕疵都记下来了。** 例如某 WIKI 概述引用了一份风之翼文本，
但该文本全文并没有它声称的那句话——这类"转述失准"在依赖二手概述时很致命，都写进了方法论综述。

**4. 考据不足的会被回头补上。** 首轮整理时有一批外部来源（英文 Fandom、中文维基、百度百科、萌娘百科）因反爬和
网络封锁没能核验，10 条考证里如实写了"未能核验"。后来把抓取链路打通，又补做了 **14 条补证**，
并在 `综述/补证后的结论修订汇总.md` 里逐条说明哪些结论被**支持**、哪些被**修正**、哪些**新增了并列说法**。

其中两处是实打实地改掉了原结论：
- 《云笈七签》**卷十三**的上尸神名是「彭**居**」，不是视频所称的「彭琚」（彭琚出自另一传本）；
- 「兹白＝驳」原本只写作"后世研究者认为"，补证找到了《逸周书·王会解》旧注**直证**：「義渠，西戎國。茲白，一名駮者也」。

**5. 未决问题单列。** `knowledge/analysis/目前仍无定论清单.md` 把 26 条尚无定论的问题
按七组列出，每条写明分歧、支持证据、以及"缺什么才能定论"。

## 怎么检索

知识原本存在本地 SQLite（FTS5 trigram 全文检索）。本仓库是它的 Markdown 导出，直接全文搜索或用目录浏览即可。
若要自行构建，见 `tools/README.md`。
